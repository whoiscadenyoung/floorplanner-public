# Floorplanner — public demo

This repository is the **deployment mirror** for the Floorplanner web app. It
exists only to publish the static demo to GitHub Pages:

**https://whoiscadenyoung.github.io/floorplanner-public/**

- The `main` branch holds this README only — there is no source code here.
- The `gh-pages` branch holds build artifacts, published automatically by a
  GitHub Actions workflow in the (private) source repository on every push to
  its `main` branch.
- Do not open pull requests here: changes will be overwritten on the next
  deploy.

Floorplanner is a local-first floor plan / interior design tool — draw walls,
place doors, windows and furniture, and see precise measurements in a unified
2D / 3D viewport. All data stays in your browser's local storage.
